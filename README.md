Project Description =
ColorVision is a simple AI & ML project that separates an image into different color regions using the K-Means Clustering algorithm.
The project groups pixels that have similar colors together — this process is called image segmentation.
It helps to simplify images, detect objects, and highlight important regions.
Users can choose how many color groups (k) they want for segmentation.
The project is made completely in Python, without using any pre-trained ML models.

4. Technologies and Algorithm Used
Language: Python
Libraries: NumPy,Matplotlib
Algorithm: K-Means Clustering (Unsupervised Learning)

6. Output =
   
The program shows the original image and its segmented version.
